# جاسم (JASEM) — دستیار صوتی فارسی ویندوز

جاسم یک دستیار هوشمند صوتی برای ویندوز است که با «هی جاسم» بیدار می‌شود،
صحبت شما را به فارسی می‌فهمد، با شخصیتی شوخ و مطمئن جواب می‌دهد و کارهای
روزمرهٔ سیستم را برایتان انجام می‌دهد — الهام‌گرفته از حس دستیارهای هوشمند
فیلم‌ها، ولی با هویت بصری و شخصیت کاملاً اختصاصی.

---

## قابلیت‌ها (پیاده‌سازی‌شده و آزموده‌شده)

| بخش | جزئیات |
|---|---|
| **شنیدن همیشگی** | تشخیص عبارت بیداری «هی جاسم»، «سلام جاسم»، «جاسم»، "Hey JASEM" به‌صورت کاملاً محلی (Vosk) — صدا از سیستم خارج نمی‌شود |
| **تشخیص گفتار** | faster-whisper (مدل `small` روی CPU با کوانتیزه INT8) + VAD وب‌رجی‌سی‌آر + تقسیم خودکار جمله با آستانه سکوت قابل تنظیم |
| **صداسازی** | صداهای عصبی فارسی Microsoft (Dilara) از طریق edge-tts بدون نیاز به کلید، و موتور کاملاً آفلاین Piper (صدای gyro) |
| **گفتگو** | مدل زبانی سازگار با OpenAI (OpenAI / OpenRouter / Groq / LM Studio / Ollama) با پخش جمله‌ای هنگام تولید، یا موتور محلی آفلاین |
| **شخصیت** | کنایه، شوخی، صمیمیت و طول پاسخ قابل تنظیم؛ پاسخ‌های متنوع و بدون تکرار |
| **اتوماسیون ویندوز** | باز کردن برنامه‌ها و سایت‌ها، جستجوی فایل، خواندن فایل متنی، وضعیت سیستم/دیسک/باتری/شبکه، کنترل صدا، ماشین‌حساب، یادداشت، یادآوری، جستجوی وب |
| **مدل مجوز** | سه سطح «عادی / نیازمند تأیید / پرریسک» + لاگ ممیزی + توقف اضطراری |
| **وقفه و قطع** | قطع فوری پخش با گفتن «هی جاسم» یا «ساکت شو» یا دکمهٔ توقف؛ محافظ اکو در برابر فعال‌شدن از صدای خود جاسم |
| **میان‌برهای سراسری** | Ctrl+Alt+J برای شروع/پایان مکالمه و Ctrl+Alt+M برای بی‌صدا (قابل تغییر در تنظیمات) |
| **رابط کاربری** | رابط تاریک آبی-نیرویی با هسته متحرک، ویژوالایزر صدا، پنل گفتگوی راست‌به‌چپ فارسی، تنظیمات صدا/شخصیت/حریم خصوصی، آیکون سینی (Tray) |
| **همراه با ویندوز** | اجرا با شروع ویندوز (فقط با انتخاب صریح شما)، ادامه کار هنگام بستن پنجره |

## تنظیم سرویس هوش مصنوعی (اختیاری)

بدون کلید هم همهٔ کارهای اتوماسیونی کار می‌کنند و جاسم به‌صورت آفلاین پاسخ
می‌دهد. برای گفتگوی عمیق‌تر، کلید یک مدل زبانی را در فایل `.env` بگذارید:

```bat
copy .env.example .env
notepad .env
```

پیشنهاد رایگان (بدون کارت بانکی) — Gemini از Google AI Studio:

```ini
OPENAI_API_KEY=<کلید رایگان از aistudio.google.com/apikey>
OPENAI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
OPENAI_MODEL=gemini-flash-lite-latest
```

یا مدل محلی بدون کلید:

```ini
OPENAI_BASE_URL=http://127.0.0.1:11434/v1   (Ollama)
OPENAI_BASE_URL=http://127.0.0.1:1234/v1    (LM Studio)
```

جزئیات سرویس‌ها، هزینه‌ها و جایگزین‌های رایگان: [`docs/API_KEYS.md`](docs/API_KEYS.md)

## نحوهٔ استفادهٔ صوتی

1. بگویید: **«هی جاسم»** (یا «سلام جاسم») — با یک صدای کوتاه تأیید، جاسم گوش می‌دهد.
2. درخواستتان را طبیعی بگویید: «برنامه کروم رو باز کن»، «فضای دیسک چقدره»، «یه یادداشت بنویس…»
3. جاسم جواب می‌دهد؛ برای قطع کافی است دوباره «هی جاسم» بگویید یا «ساکت شو».
4. مکالمه تا ۴۵ ثانیه سکوت ادامه دارد؛ نیازی به تکرار عبارت بیداری نیست.
5. برای عملیات حساس، جاسم ابتدا می‌پرسد و با «بله»/«خیر» (صدایی یا با دکمه) تأیید می‌شود.
6. دکمهٔ 🎙 یا کلید Enter در کادر متن، حالت دستی است؛ کلیدهای توقف/تکرار/بی‌صدا هم کنار پنجره هستند. میان‌برهای سراسری: **Ctrl+Alt+J** (مکالمه) و **Ctrl+Alt+M** (بی‌صدا) — حتی وقتی پنجره بسته و جاسم در سینی ویندوز است.

## معماری

```
src/jasem/
├── app.py               نقطه شروع و CLI (--check / --smoke)
├── orchestrator.py      هماهنگ‌کنندهٔ اصلی + خط لولهٔ گفتار
├── state_machine.py     ماشین وضعیت صوتی (idle…speaking…error)
├── config.py            پیکربندی تایپ‌شده (JSON در %APPDATA%\JASEM)
├── audio/               ضبط میکروفن، VAD، پخش با قطع فوری
├── stt/                 موتور faster-whisper، تقسیم جمله، اصلاح واژه‌ها
├── wake/                تشخیص عبارت بیداری با Vosk (محلی)
├── tts/                 edge-tts (ابری) و Piper (آفلاین) + آماده‌سازی متن گفتاری
├── ai/                  ارائه‌دهندهٔ مدل زبانی، حافظهٔ مکالمه، شخصیت
├── nlp/                 نرمال‌سازی فارسی، تشخیص قصد آفلاین
├── automation/          اکشن‌های ویندوز + سیاست مجوز + ممیزی
├── hotkeys.py           میان‌برهای سراسری ویندوز (RegisterHotKey)
└── ui/                  پل Qt + رابط QML آینده‌نگر (RTL)
tests/                   ۱۲۴ تست واحد و یکپارچه
eval/                    ارزیاب WER/CER و مجموعهٔ ۳۰ جمله‌ای فارسی
```

## پیکربندی

- فایل پیکربندی کاربر: `%APPDATA%\JASEM\config.json` (همهٔ گزینه‌ها در `config.example.json`)
- لاگ‌ها: `%APPDATA%\JASEM\logs\jasem.log` (بدون کلید و بدون صدا)
- لاگ ممیزی اکشن‌ها: `%APPDATA%\JASEM\audit.log`
- تاریخچه/حافظه: `%APPDATA%\JASEM\history.json` و `memory.json` (هر دو با یک کلیک قابل پاک‌کردن از تنظیمات)

## حریم خصوصی

- تشخیص عبارت بیداری **کاملاً محلی** است؛ صدای خام برای بیدارشدن به هیچ سروری نمی‌رود.
- گفتار شما فقط هنگامی که فعال شده باشید به موتور تشخیص گفتار محلی (Whisper) می‌رود.
- اگر صداسازی edge را انتخاب کنید، **متن جواب** به سرویس Microsoft ارسال می‌شود (صداهای عصبی). برای حداکثر حریم خصوصی موتور `piper` را از تنظیمات انتخاب کنید — کاملاً آفلاین.
- مدل زبانی ابری فقط وقتی کلید تنظیم کرده باشید فعال است و فقط متن مکالمه را می‌فرستد.
- حافظهٔ بلندمدت پیش‌فرض **خاموش** است و هر وقت بخواهید با یک دکمه پاک می‌شود.
- خاموش کردن میکروفن از دکمهٔ 🎙 فوراً هر گوش‌دادن را متوقف می‌کند.

## محدودیت‌های صادقانه

1. **دقت عبارت بیداری:** تشخیص مبتنی بر بازشناسی گفتار محلی است (نه مدل کلمه-کلیدی جداگانه). در سکوت خانگی خوب عمل می‌کند؛ در محیط پرنویز ممکن است چند بار تکرار لازم باشد. عبارت «جاسم» تنها وقتی ایزوله بیان شود فعال می‌شود تا جملات معمولی مزاحم نشوند.
2. **تأخیر فعال‌سازی:** بین پایان عبارت بیداری و آماده‌شدن برای درخواست، حدود ۰٫۵ تا ۱ ثانیه طول می‌کشد (طبیعی برای این معماری).
3. **بدون کلید مدل زبانی:** پاسخ‌های گفتگویی الگویی و محدود است؛ اکشن‌های سیستمی کامل کار می‌کنند.
4. **صداهای آفلاین Piper** طبیعی‌ترین صدای فارسی موجود به‌صورت رایگان نیستند؛ صدای edge (Dilara) بسیار طبیعی‌تر است ولی آنلاین است.
5. **اکو گارد ساده است:** جاسم متن‌هایی را که خودش اخیراً گفته نادیده می‌گیرد، ولی در بلندگو (نه هدست) ممکن است استثنائاتی پیش بیاید — در تنظیمات می‌توانید قطع صدا با صدا را خاموش کنید.
6. **اتوماسیون همه‌چیز را پوشش نمی‌دهد:** کنترل پنجره‌های غیراستاندارد و برنامه‌های بدون رابط کاربری استاندارد محدود است؛ برنامه‌ها از منوی Start ویندوز شناسایی می‌شوند.

## عیب‌یابی

راهنمای کامل: [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md)

مشکلات رایج:
- **صدایی نمی‌شنوم:** `--check` بزنید؛ میکروفن پیش‌فرض ویندوز را چک کنید.
- **«هی جاسم» کار نمی‌کند:** در تنظیمات «گوش دادن همیشگی» روشن باشد؛ مدل vosk دانلود شده باشد.
- **جواب صوتی ندارد:** اینترنت برای edge لازم است؛ یا از موتور `piper` آفلاین استفاده کنید.
- **مدل زبانی جواب نمی‌دهد:** کلید `.env` و آدرس پایه را چک کنید؛ جاسم در حالت آفلاین به کار خود ادامه می‌دهد.
