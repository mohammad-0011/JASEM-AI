# کلیدهای API، هزینه‌ها و منابع سیستمی

## وضعیت پیش‌فرض: بدون هیچ کلیدی

جاسم بدون هیچ حساب یا کلیدی کار می‌کند:

| قابلیت | بدون کلید |
|---|---|
| گوش دادن همیشگی + بیداری «هی جاسم» | ✅ کاملاً محلی (Vosk) |
| تشخیص گفتار فارسی | ✅ محلی (faster-whisper) |
| صداسازی آفلاین | ✅ محلی (Piper — صدای gyro) |
| صداسازی طبیعی | ✅ رایگان با edge-tts (نیاز به اینترنت، بدون کلید) |
| اتوماسیون ویندوز | ✅ محلی |
| گفتگوی عمیق و چندمرحله‌ای | ⚠️ پاسخ محلیِ محدود (الگویی) |

## سرویس‌های اختیاری

### ۱) مدل زبانی (برای گفتگوی واقعی)

سازگار با هر سرویسی که API سازگار با OpenAI بدهد. هر سه مقدار زیر را در فایل `.env` بگذارید
(الگوی آماده: [`.env.example`](../.env.example)):

```dotenv
OPENAI_API_KEY=<کلید شما>
OPENAI_BASE_URL=<آدرس پایهٔ سرویس>
OPENAI_MODEL=<شناسهٔ مدل>
```

### گزینه‌های رایگان بدون کارت بانکی (پیشنهادی)

| سرویس | `OPENAI_BASE_URL` | `OPENAI_MODEL` پیشنهادی | سقف رایگان | ساخت کلید |
|---|---|---|---|---|
| **Google AI Studio (Gemini)** ⭐ | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-flash-lite-latest` (یا `gemini-flash-latest` در صورت ۵۰۳) | رایگان بدون کارت؛ سقف به ازای هر مدل/پروژه در AI Studio نمایش داده می‌شود | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| **Groq** | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` | ۳۰ درخواست/دقیقه، ۱۰۰۰ درخواست/روز | [console.groq.com/keys](https://console.groq.com/keys) |
| **OpenRouter** | `https://openrouter.ai/api/v1` | مدل‌های `:free` | حدود ۵۰ درخواست روزانه روی مدل‌های رایگان | [openrouter.ai/keys](https://openrouter.ai/keys) |

پیشنهاد ما برای فارسی: **Gemini** (بهترین کیفیت گفتگوی فارسی در میان گزینه‌های رایگان).

### سرویس‌های پولی / محلی

| سرویس | کلید | هزینهٔ تقریبی | توضیح |
|---|---|---|---|
| **OpenAI** | `OPENAI_API_KEY` + `OPENAI_MODEL=gpt-4o-mini` | به ازای توکن؛ `gpt-4o-mini` بسیار ارزان | باکیفیت‌ترین گزینه |
| **LM Studio / Ollama** | بدون کلید + `OPENAI_BASE_URL=http://127.0.0.1:1234/v1` | رایگان، کاملاً محلی | به رم و ترجیحاً GPU نیاز دارد؛ کیفیت به مدل بستگی دارد |

### ۲) صداسازی

| موتور | کلید | هزینه | کیفیت/نکته |
|---|---|---|---|
| **edge-tts** (پیش‌فرض) | ندارد | رایگان | صدای عصبی Dilara (مایکروسافت). غیررسمی و ممکن است محدود شود؛ جاسم خودکار به Piper برمی‌گردد. |
| **Azure Speech** (مستقیم) | کلید Azure | ۵۰۰ هزار کاراکتر رایگان در ماه (F0)؛ بعد از آن پرداخت به ازای کاراکتر | پشتیبانی رسمی؛ نیاز به ساخت منبع Speech در Azure |
| **Piper** (آفلاین) | ندارد | رایگان | کاملاً محلی؛ کیفیت قابل قبول، کمی رباتیک‌تر از edge |

### ۳) تشخیص گفتار و بیداری — همیشه محلی

هیچ صدایی برای تشخیص عبارت بیداری ارسال نمی‌شود. مدل‌ها رایگان و متن‌باز هستند:

| مدل | اندازه | منبع |
|---|---|---|
| vosk-model-small-fa-0.42 | ۵۳ MB | alphacephei.com |
| vosk-model-small-en-us-0.15 | ۱۸ MB | alphacephei.com |
| faster-whisper small | ~۴۶۰ MB | Hugging Face (Systran) |
| Piper fa_IR-gyro-medium | ~۶۳ MB | Hugging Face (rhasspy/piper-voices) |

## منابع سیستمی (اندازه‌گیری‌شده روی Ryzen 9 7900 / 32GB)

| عملیات | هزینه |
|---|---|
| گوش دادن همیشگی (Vosk فارسی+انگلیسی) | ≈ ۱ تا ۲٪ CPU |
| تشخیص گفتار هر جمله (whisper small int8) | ~۱ ثانیه برای هر ثانیه صدا؛ آماده‌سازی مدل ~۲ ثانیه |
| صداسازی آفلاین Piper | ~۰٫۵–۱ ثانیه برای هر جمله |
| صداسازی edge (اینترنت) | ~۰٫۵–۲ ثانیه تا اولین صدا |
| حافظهٔ کل برنامه (با همهٔ مدل‌ها) | ~۱٫۵ تا ۲ گیگابایت رم |

پیشنهاد: ۴ گیگابایت رم آزاد و CPU چهارهسته‌ای کافی است. برای کیفیت بهتر
تشخیص گفتار می‌توانید `stt.model_size` را `medium` یا `large-v3` کنید (کندتر).

## حریم خصوصی ارسال داده

| داده | کجا می‌رود |
|---|---|
| صدای عبارت بیداری | هیچ‌جا — پردازش کاملاً محلی |
| صدای درخواست شما | محلی (Whisper روی همین کامپیوتر) |
| متن مکالمه | فقط اگر کلید مدل زبانی تنظیم کرده باشید، به همان سرویس می‌رود |
| متن پاسخ برای صداسازی edge | به سرویس Microsoft (اگر موتور edge انتخاب شده باشد) |
| کلیدهای API | فقط در `.env` محلی؛ در لاگ‌ها ماسک می‌شوند |
