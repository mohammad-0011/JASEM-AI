# نتایج تست‌های واقعی جاسم

همهٔ اعداد زیر روی همین سیستم (Ryzen 9 7900، ۳۲ گیگ رم، ویندوز ۱۱، Python 3.10)
اندازه‌گیری شده‌اند — نه تخمین.

---

## ۱) تست‌های خودکار

```
pytest tests -q -k "not integration"   →  115 passed
pytest tests/test_integration_audio.py →  7 passed
```

پوشش تست‌های واحد: نرمال‌سازی فارسی، عبارت‌های بیداری، قصد آفلاین، سیاست مجوز،
اعتبارسنجی اکشن‌ها، ماشین وضعیت، تقسیم جملهٔ بلادرنگ، تاریخچهٔ مکالمه، آماده‌سازی
متن گفتاری، لایهٔ اصلاح واژه، پیکربندی، محاسبهٔ WER/CER، گردآورندهٔ گفتار (با صدای
مجازی: سکوت/گفتار/مکث میانی)، پارسر میان‌برهای سراسری.

## ۵) ارزیابی WER/CER (مجموعهٔ ۳۰ جمله‌ای فارسی)

روش: `eval/corpus/fa_eval.jsonl` با صدای Piper (gyro) سنتز و با هر دو موتور بازخوانی
شد. قالب کامل: `eval/report.json`.

| موتور | WER | CER |
|---|---|---|
| vosk-model-small-fa-0.42 | **0.272** | **0.080** |
| faster-whisper-small (int8, CPU) | 0.692 | 0.240 |

**تفسیر صادقانه:** این اعداد روی **صدای مصنوعی Piper** اندازه‌گیری شده است، نه
گفتار انسانی. Piper صداهای محاوره‌ای («چطوره»، «میشه») را اندکی متفاوت ادا می‌کند و
هر دو موتور روی آن افت می‌کنند؛ در این شرایط Vosk عملکرد بهتری داشت. برای گفتار
انسانی واقعی، Whisper عموماً مقاوم‌تر است (به‌ویژه برای جملات طولانی، نویز و
ترکیب فارسی-انگلیسی). به همین دلیل پیش‌فرض برنامه Whisper است و Vosk برای
تست‌های مقایسه‌ای در دسترس است:

```bat
.venv\Scripts\python eval\evaluate_stt.py --engines vosk faster-whisper --synth edge
```

برای اندازه‌گیری روی صدای انسان، فایل‌های WAV واقعی خود را در `eval/audio/` با
نام‌های `s01.wav` … بگذارید و `--rebuild-audio` نزنید.

قطع فیزیکی سخت‌افزار.
